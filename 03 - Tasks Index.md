## Como reportar un bug

1. Crear una nota nueva con `Ctrl+N`
2. Aplicar template `Bug Report` con `Ctrl+T`
3. Llenar los campos: titulo, severity, pasos para reproducir
4. Agregar tag `#bug` si no esta自动amente

## Como pedir una feature

1. Crear una nota nueva con `Ctrl+N`
2. Aplicar template `Feature Request` con `Ctrl+T`
3. Describir que功能 queres y por que
4. Agregar tag `#feature`

## Estados posibles

- `abierto` - Recien creado, sin analizar
- `en-progreso` - Alguien esta trabajando en ello
- `resuelto` - Ya esta implementado/fixed
- `descartado` - No se va a hacer

## Etiquetas utiles

- `#bug` - Problemas
- `#feature` - Nuevas funcionalidades
- `#mejora` - Optimizaciones
- `#urgente` - Requiere atencion inmediata
